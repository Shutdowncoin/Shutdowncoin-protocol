# Shutdown Whitepaper

## Vision & Mission

**Vision.** A market surface that stays readable when attention is scattered: one switch, one board, no clutter between a person and the numbers.

**Mission.** Keep a plain, always-on window onto Solana activity, and keep every claim about Shutdown itself pinned to a single registry of stated facts. If a fact is not stated, the site shows nothing in its place.

## Principles

1. **Register first.** Contract address, links and data sources are records. Each is stated, absent or unconfirmed, and only stated records produce links or actions.
2. **Match, never guess.** Addresses are compared to the registry. Shape alone never decides trust.
3. **Tape before token.** The market board runs on public feeds and never depends on Shutdown's own token existing.
4. **No clocks.** The interface shows values, not timestamps.

## Roadmap

**Phase 1: Switch on.** Launch the site, the live board and the registry. Publish the X profile.

**Phase 2: Mint.** State the contract address in the registry. The address slot goes live, the pinned own-token row switches from placeholder to live data, and the checker begins matching.

**Phase 3: Depth.** Extend the board with richer per-token views, saved filters and a lighter mobile layout.

**Phase 4: Open.** Publish the source repository, document the register format and invite outside contributions.
